# Water Quality Monitor

Estimates river turbidity (how cloudy or muddy the water is) from Sentinel-2 satellite imagery,
converts it into a risk score, and shows it in a Streamlit dashboard.

**Status:** runs locally and in Docker. Not publicly deployed.

## How it works

1. **Water detection:** for a location and date window, fetch the clearest Sentinel-2 image from
   Google Earth Engine and mark water pixels with NDWI > 0.
2. **Features:** mean, std and median reflectance per band over water pixels in a 250 m buffer,
   plus three band ratios (47 features).
3. **Model:** a Random Forest trained on Earth Engine reflectance matched to USGS continuous
   turbidity sensors.
4. **Risk score:** status (Clean ≤ 5, Moderate ≤ 25, Polluted > 25 FNU) plus a percentile among
   historical sensor readings.
5. **Dashboard:** single location, multi-station map, and trend over time.

## Results

| Model (same 8 held-out stations) | R² | MAE (FNU) |
|---|---|---|
| Median baseline | -0.62 | 23.81 |
| USGS-trained model fed Earth Engine features | 0.77 | 8.37 |
| **Earth Engine-trained model (used by the app)** | **0.81** | **6.37** |

- Train/test split is **by station**, so the test measures performance at places the model has
  never seen.
- Training data: 1,922 satellite scenes from 35 stations. Test: 457 scenes from 8 stations.
- Small test set, no confidence interval. Outputs are screening-level estimates, not measurements.

## Findings worth knowing

- **Train/serve skew:** the first model was trained on USGS's own reflectance, but the app uses
  Earth Engine's. On the same station and dates, the error roughly doubled (MAE 3.9 to 7.9),
  so I rebuilt the training table from Earth Engine itself.
- **Effective sample size:** about 250K sensor readings map to only about 2,700 distinct
  satellite scenes, because readings from one pass share the same reflectance.
- **Negative results:** chlorophyll and CDOM models did not generalize to unseen stations
  (R² below 0) and are not shipped.
- **Known gaps:** the 5 and 25 FNU thresholds are not yet tied to a cited source, and one
  reservoir station (Willow Creek) failed in the first model for reasons I could not explain.

## Run it

Data and model files are not in the repo. You need:
- the USGS dataset "Aquatic reflectance data, Sentinel-2 imagery paired with continuous water
  quality" [dataset](https://www.usgs.gov/data/aquatic-reflectance-data-sentinel-2-satellite-imagery-paired-continuous-water-quality) in a `data/` folder next to `scripts/`
- a Google Earth Engine account with an authenticated project
- the model files `turbidity_model_gee.pkl`, `turbidity_features_gee.pkl` and
  `turbidity_reference.pkl`, generated by the training notebook, placed in `scripts/`

```
cd scripts
pip install -r requirements.txt
streamlit run app.py
```

**Tests** (no Earth Engine login needed):

```
cd scripts
pytest
```

**Docker:**

```
cd scripts
docker build -t water-quality-app .
docker run -p 8501:8501 -v "$env:USERPROFILE\.config\earthengine:/root/.config/earthengine" water-quality-app
```
